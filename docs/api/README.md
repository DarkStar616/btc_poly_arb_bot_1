# API Documentation

This directory contains (partial) OpenAPI specifications for the external APIs used by the Polymarket Paper Bot.

## Specifications
- [Polymarket Gamma](polymarket_gamma.openapi.yaml): Market discovery endpoints.
- [Polymarket CLOB](polymarket_clob.openapi.yaml): Central Limit Order Book endpoints.
- [Binance WS](binance_ws.openapi.yaml): Real-time trade streams.
